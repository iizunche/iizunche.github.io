# Хронология эпизодов для MyBB

Готовый статический виджет: три карточки в ряд, автоматический перенос на следующую строку, фильтры «Все / Открытые / Закрытые», счётчики и сортировка.

## Файлы

- `index.html` — структура виджета.
- `style.css` — оформление.
- `script.js` — загрузка JSON, фильтрация и сортировка.
- `episodes.json` — редактируемые данные эпизодов.

## Как добавить или изменить эпизод

Редактируйте только `episodes.json`. Каждый эпизод — объект с четырьмя полями:

```json
{
  "title": "Название эпизода",
  "date": "2026-11-01",
  "url": "https://адрес-темы-на-форуме",
  "status": "open"
}
```

- `title` — название.
- `date` — дата в формате `ГГГГ-ММ-ДД`.
- `url` — ссылка на тему MyBB. Если ссылки нет, поле можно убрать.
- `status` — строго `open` или `closed`.

После изменения JSON сохраните файл и дождитесь обновления сайта. Скрипт запрашивает JSON без кеша браузера.

## Сортировка

В режиме «Все эпизоды» открытые идут первыми, затем закрытые. Внутри каждой группы порядок от более новых дат к более старым. Фильтры позволяют отдельно показывать открытые или закрытые.

## Публикация через GitHub Pages

1. Создайте публичный GitHub-репозиторий.
2. Загрузите в корень репозитория все четыре файла (README можно оставить для себя).
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch, ветку `main` и папку `/ (root)`.
5. Сохраните настройки и дождитесь публикации.
6. Откройте выданный GitHub Pages URL и проверьте, что карточки появились.

При обновлении списка эпизодов меняйте `episodes.json` в репозитории. Остальные файлы трогать не нужно.

## Встраивание в MyBB

Вставьте в сообщение HTML iframe, если ваш форум и настройки разрешают такой MyCode:

```html
<iframe
  src="https://ВАШ-АККАУНТ.github.io/ВАШ-РЕПОЗИТОРИЙ/"
  width="100%"
  height="700"
  frameborder="0"
  loading="lazy"
  title="Хронология эпизодов">
</iframe>
```

Замените адрес на URL опубликованного виджета. Если MyBB не отображает iframe, понадобится администраторская настройка разрешённого MyCode или плагин iframe. Не пытайтесь вставлять JavaScript в текст сообщения.

Высота `700` — стартовое значение: увеличьте её, если эпизодов станет больше. При фиксированной высоте длинная хронология будет прокручиваться внутри iframe.

## Примечания

- Макет намеренно не адаптируется под мобильные экраны: всегда остаются три колонки.
- Фон страницы прозрачный, сам виджет имеет светлую нейтральную подложку.
- Внешний шрифт загружается из Google Fonts; при недоступности используются системные запасные шрифты.
- Ссылки открываются в новой вкладке.
